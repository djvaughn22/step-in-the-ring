# Ready to Build: evidence for the real-project cards

Reviewed 2026-09-20. Read-only inspection of local repositories; all edits
belong to Step In The Ring. Public copy describes specific verified features,
not every route in each product. Source code proves implementation, not a
provider partnership, current production credentials, or a measured bill.

## CrossHeartPray

Local checkout: `OpenMirror/crossheartpray`, HEAD `75f4620`.

- `src/lib/scripture/localDatasets.ts`: stored BSB, WEBUS, and KJV text.
- `src/lib/bibleReadingPlan.ts`: structured reading-plan data and original PDF.
- `src/app/api/scripture/chapter/route.ts`: local-text lookup; other versions
  use the YouVersion connection only with a server key and an enabled version.
- `src/lib/scripture/provider.ts`: the reader calls the chapter endpoint and
  caches chapters; Scripture is not generated by a language model.
- AI development evidence: commit `7982ad8`, “Add a 2 Year / 104 Week pace to
  the Bible Reading Plan,” co-authored by Claude Opus 5, changes the interface,
  progress code, plan files, and tests.

The card says the code supports the developer connection. It does not claim
that a particular licensed translation is currently enabled in production.

## TheDJCares

Local checkout: `TheDJCares/thedjcares`, HEAD `d181b9a`.

- `app/lib/djCaresLibrary.ts`: approved catalog with video IDs, Apple Music
  and Spotify embeds, and audio URLs.
- `app/lib/spin.ts`: ordinary selection code over that catalog.
- `app/components/DJPlayer.tsx`: playback controls.
- `app/lib/digitalDjAiParser.ts` and
  `app/api/digital-dj/parse-intent/route.ts`: optional AI maps a typed request
  to validated filters; it cannot invent catalog URLs or media IDs. Failure
  falls back to ordinary selection. The feature flag defaults to enabled,
  so the copy does not describe AI as universally disabled.
- AI development evidence: `5244790` (volume controls) and `7f778ef`
  (playback auto-advance fix), with Claude co-author trailers.

The no-required-AI observation is scoped to browsing and playback, not every
special feature or service charge.

## iDontCry

Local checkout: `idontcry`, HEAD `bf8b682` at inspection.

- `src/app/sports/page.tsx`: Sports Desk reads stored teams, events, and
  college fixtures, then constructs the visible desk.
- `src/lib/sports/followed/store.ts`: committed sports files and an optional
  stored-data overlay. `data/sports/` contains the source records.
- `src/lib/sports/sources/eventlink.ts`: school calendar JSON; explicitly
  supplies schedules and cancellations, never scores.
- `src/lib/sports/sources/sidearmSchedule.ts` and
  `src/lib/sports/collegeFixtures.ts`: college athletics source parsing and
  stored fixtures. Availability depends on the source and refresh process.
- `scripts/collector/collect.sh`: collection is separate from ordinary page
  reads. This script was inspected, not executed.
- AI development evidence: `ec6e509`, Sports Desk visual/navigation work,
  co-authored by Claude Sonnet 5. `bf8b682` preserves the distinction between a
  passed date and a confirmed result.

The card links to `/sports` and does not imply that all iDontCry features are
AI-free or that every score is available. No private user or family records
were used as examples.

## WatchedNotWatched

Local checkout: `WatchedNotWatched/watched-not-watched`, HEAD `7ee06f1`.

- `src/app/api/search/route.ts`: Open Library for books; TMDB when configured;
  TVmaze fallback for television. These are the active routing choices.

  timeouts, retries, and caching of successful detail responses.
- `src/app/api/recommendations/route.ts`,
  `src/lib/recommendations/config.ts`: ordinary candidate retrieval and

- AI development evidence: `a5ca0b5` (Open Library book model/search support),
  `cf19c36` (detail reliability, caching, tests), and `7ee06f1` (book mode and
  link truthfulness), all with Claude co-author trailers.

primary provider. That conflicts with current routes and the source registry;
it was not used for public provider or price claims. No current provider
pricing, production key configuration, or commercial license was verified.
